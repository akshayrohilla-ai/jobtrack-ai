1. Product Vision

"Stop applying blindly — know if a job is worth your time before you apply."

JobTrack AI is the intelligence layer missing from every job search. It reads your CV, grades every job you consider, rewrites your application for that specific role, and prepares you for the interview — all in under 5 minutes, all personalised to you specifically.

3. Feature Inventory

📄 CV Parsing Free · Always

Upload PDF or DOCX. AI (Haiku 4.5) extracts name, email, phone, LinkedIn, title, location, years of experience, seniority level, domain, up to 25 skills, and a 2–3 sentence summary. Profile saved to database and restored on every login. Raw CV text stored for use in tailoring and interview prep.

🎯 JD Evaluation 1 Credit

Paste any job description. AI (Sonnet 4.6, prompt-cached) returns: A–F grade with reasoning, role summary, company culture signals, matched skills, gaps with mitigation, salary range estimate (INR), red flags, green flags, and a go/no-go recommended action. Result downloadable as formatted HTML report. Evaluation saved to history. JD text and result persisted in localStorage — survives browser refresh.

✨ CV Tailoring 1 Credit

AI (Sonnet 4.6) rewrites the full CV against the evaluated JD. Output includes: rewritten professional summary, reordered/optimised skills, rewritten experience bullets with JD language and quantified impact, application briefing (lead with, mirror these phrases, downplay), education, certifications. Downloadable as formatted DOCX with real contact details. Requires both CV parsed and JD evaluated.

🎤 Interview Prep 1 Credit

AI (Sonnet 4.6) generates a personalised interview pack: 5 behavioural questions tailored to the JD, full STAR answers written from the actual CV, key JD phrases to mirror in each answer, 2 red-flag weak spots with framing advice, 4 smart role-specific questions to ask the interviewer. Downloadable as HTML report. Requires both CV and JD eval. Result persists across tab switches.

🔍 AI Job Search Free

Search jobs by role, location, seniority, and recency. Results from external job API. One-click apply saves job to tracker with pre-filled details.

📊 Application Tracker Free

Kanban board with columns: Applied, Interview, Offer, Rejected. Applications persist in database. Count shown in tab nav badge. Editable — update status, add notes.

📈 Dashboard Free

Visual summary of application pipeline — count by status, recent activity. For the user to understand their job search at a glance.

👥 Recruiter Mode Admin Only (Coming Soon for others)

Analyse a JD to extract required skills. Upload candidate CVs one by one — AI scores each against the JD, shows matched/missing skills and a fit percentage. Build a shortlist. Export shortlist as CSV. Currently restricted to admin user only.

🧠 Mock Interview Coming Soon

User answers behavioural questions in text. AI evaluates the answer for STAR completeness, pacing, and delivery. Gives structured feedback. Building on Interview Prep foundation.

5. Navigation Structure

Job Seeker Mode tabs (in order): My Profile → Find Jobs → Evaluate JD → Tailor CV → Interview Prep → Tracker → Dashboard

Recruiter Mode tabs: Analyse JD → Score Candidates → Shortlist

Special routes: /admin (admin dashboard), /reset-password (password recovery), /privacy, /terms, /refund, /contact

Mode toggle: Job Seeker always available. Recruiter shows "Coming Soon" tooltip for non-admin users.

6. Authentication

  • Supabase Auth — email/password
  • Sign up, sign in, forgot password (reset email), password reset page (/reset-password)
  • JWT passed in Authorization header on all API calls
  • Session persists via Supabase client — restored on page load
  • Unauthenticated users see Landing Page only

7. Payments

  • Razorpay integration — create order → frontend Razorpay modal → verify payment
  • HMAC-SHA256 signature verification on backend before crediting
  • Payment logged to payment_log table
  • Credits added to credits table atomically with payment verification
  • 503 returned if Razorpay keys not configured
