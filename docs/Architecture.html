4. Anthropic API Usage

FeatureModelMax TokensCachingCost/call
CV Parsingclaude-haiku-4-5-202510011,024No~$0.003
JD Evaluationclaude-sonnet-4-61,500Yes (system prompt >1024 tokens)~$0.030
CV Tailoringclaude-sonnet-4-63,000Yes~$0.042
Interview Prepclaude-sonnet-4-62,000Yes~$0.044
Prompt Caching: JD evaluation, CV tailoring, and interview prep all use cache_control: ephemeral on their system prompts. First call pays 1.25x write cost. Subsequent calls pay 0.1x (90% discount). Cache TTL is 5 minutes. This significantly reduces cost in production.

6. Security Architecture

Authentication Flow

User signs in
→
Supabase returns JWT
→
Frontend stores in session
→
Every API request sends Bearer token
→
Backend verifies via supabase.auth.get_user(token)

Layers of Security

LayerMechanismProtects Against
JWT verificationEvery backend endpoint calls get_current_user(request)Unauthenticated access
Admin checkHardcoded admin user_id checked on /api/admin/*Non-admin accessing admin panel
Credit checkrequire_credits() before any AI callFree-riding, balance manipulation
Rate limitingslowapi 10/min per IP on AI endpointsAbuse, brute force
Payment verificationHMAC-SHA256 signature check before creditingFake payment callbacks
RLS (Supabase)Per-user policies on all 9 tablesJWT holder reading other users' data directly
Service role keyBackend uses service role — bypasses RLS by designBackend always has full access; policies protect direct DB access
CORSALLOWED_ORIGINS env var — only jobtrackai.co.in permitted in productionCross-origin request forgery
Error sanitisationGeneric messages returned to frontend; details logged server-side onlyInformation leakage

8. Deploy Pipeline

  • GitHub repo: akshayrohilla-ai/jobtrack-ai (main branch)
  • Frontend: Push to main → Vercel auto-builds and deploys in ~60 seconds
  • Backend: Push to main → Render auto-builds and deploys in ~2 minutes
  • Database: Manual migrations run in Supabase SQL Editor
  • Rollback: Vercel — instant rollback to previous deployment. Render — redeploy from previous commit.
