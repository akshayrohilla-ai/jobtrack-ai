1. New User Signup & First Session

1
User visits jobtrackai.co.in
Not authenticated → Landing Page shown
2
Clicks "Get Started Free" → AuthModal opens
Sign Up tab shown by default
3
User enters email + password → submits
supabase.auth.signUp() called
4
Supabase creates auth.users record
DB trigger fires automatically: inserts credits row with balance=3
5
User auto signed-in, JWT stored in session
App renders, credit balance fetched: shows "3 credits"
6
My Profile tab shown — user prompted to upload CV
restoreFromDB() runs silently — no profile found yet (404), silent ignore

2. CV Upload & Parsing

1
User drops PDF/DOCX file on upload zone
File validated: type (pdf/docx/txt), size (<10MB)
2
POST /api/cv/parse — JWT verified, no credit check
Text extracted: PyPDF2 (PDF) or python-docx (DOCX)
3
Haiku 4.5 parses CV text → JSON
Extracts: name, email, phone, linkedin, title, location, years_exp, seniority, domain, skills (25), summary, initials
4
Profile saved to cv_profiles table
Including email, phone, linkedin, raw_text (12K chars)
5
Profile displayed on My Profile card
raw_text stored in sessionStorage (key: jobtrack_raw_cv). Profile state set in SeekerMode.

3. JD Evaluation

1
User pastes JD text, enters role/company (optional)
Minimum 50 chars required
2
POST /api/evaluate/evaluate-jd — JWT verified
Rate check: 10/min per IP
3
Credit check: balance ≥ 1?
If no: 402 → frontend opens PaymentModal. If yes: balance decremented by 1, usage_log row inserted.
4
Sonnet 4.6 evaluates JD against CV profile
System prompt cached (ephemeral). Returns: grade, role_summary, cv_match, gaps, salary_range, red_flags, green_flags, recommended_action
5
Evaluation saved to jd_evaluations table
6
Result displayed. Saved to localStorage.
evalResult, evalJdText, evalRole, evalCompany all persisted. Survives browser refresh.

4. CV Tailoring

1
User navigates to Tailor CV tab
Checklist shown: CV parsed ✓, CV text loaded ✓, JD evaluated ✓ — all must be green to enable button
2
POST /api/tailor/tailor-cv — JWT, credit check, deduction
Sends: jd_text, cv_raw_text, cv_profile
3
Sonnet 4.6 rewrites CV for the specific JD
Returns: professional_summary, skills, experience, technical_projects, certifications, education, application_briefing
4
Result displayed in UI. State lifted to SeekerMode.
Result persists across tab switches. No "Tailor again" button — prevents accidental credit spend.
5
User clicks Download CV (.docx)
DOCX generated entirely in browser using docx npm package. contact details from profile inserted. Downloaded as {Name}-tailored-CV-{date}.docx

5. Interview Prep

1
User navigates to Interview Prep tab
Same checklist as Tailor CV. All 3 must be green.
2
POST /api/interview/prep — JWT, credit check, deduction
3
Sonnet 4.6 generates interview pack
Returns: 5 behavioral questions with STAR answers, 2 red flags with framing, 4 questions to ask interviewer
4
If AI fails: credit automatically refunded
refund_credits() called. User sees "your credit has been refunded" message.
5
Result shown — expandable STAR cards, red flags, questions
State lifted to SeekerMode. Download prep button → HTML file → user prints to PDF.

6. Payment Flow

1
User clicks + Buy or PaymentModal triggered by 402
2
POST /api/payments/create-order with pack_id
Razorpay order created. Returns order_id, amount, currency. 503 if keys not configured.
3
Razorpay modal opens in browser
User completes payment via UPI / card / netbanking
4
POST /api/payments/verify-payment
HMAC-SHA256 signature verified. If valid: credits added to credits table, payment_log row inserted.
5
Credit balance updated in header. Modal closes.

7. Returning User Session Restore

1
User opens app (returning, session stored in browser)
2
supabase.auth.getSession() → JWT valid → user set
3
GET /api/evaluate/balance → credit balance shown in header
4
GET /api/cv/profile → profile restored
name, email, phone, linkedin, title, skills all restored into state
5
raw_text restored from sessionStorage if present
If not in sessionStorage but in DB: restored from raw_text column
6
JD eval state restored from localStorage
evalResult, evalJdText, evalRole, evalCompany — user can go straight to Tailor or Interview Prep without re-evaluating

9. Full Cycle — Ideal User Journey

Landing Page
    ↓ Sign up (3 free credits granted)
My Profile → Upload CV (free)
    ↓ Profile shown: name, skills, seniority
Evaluate JD → Paste JD, click Evaluate (-1 credit)
    ↓ Grade A shown, 12 skills matched, salary ₹9-15L
Tailor CV → Click Tailor CV for this role (-1 credit)
    ↓ Rewritten CV shown, Download .docx
Interview Prep → Click Generate (-1 credit)
    ↓ 5 STAR answers, 2 red flags, 4 questions to ask
    ↓ Download prep pack as HTML → print to PDF

Total: 3 credits used = free signup credits fully consumed
User buys ₹199 pack (10 credits) to continue
